# 09: 在定制界面和缺少可选服务时完成内容流程

**What to build:** 商户能在既有品牌和功能范围内，从日历进入媒体库，完成编辑、上传和排程并查看分析。收件人可匿名查看有效的公开预览。

**Blocked by:** [01 合入固定版本并跑通候选版](01-merge-and-run-candidate.md)

**Status:** ready-for-agent

**Source:** [升级规格](../../postiz-v2.26.0-wayfinder/spec.md) · [继承的界面及可选服务契约](../../postiz-v2.26.0-wayfinder/../postiz-stable-merge/spec.md)

- [ ] 在桌面和移动布局核对主布局 Logo、默认浅色、SSO 浅色及手动深色切换。检查 Agent、Settings、删除账户、永久交换登录身份与指定媒体工具的隐藏范围，管理员仍可使用原代入入口。
- [ ] 用实际页面完成媒体导入、单媒体编辑、上传、选择和插入，从日历排程并打开分析。核对上游平台图标、普通成员和管理员的账单权限反馈。
- [ ] 在匿名窗口打开有效预览，并对不存在或无效内容核对既有回退结果。
- [ ] 在缺少可选 AI/媒体服务的隔离配置下跑通上述核心路径。已鉴权且有权限的 AI 请求收到既有 503；让 MCP 启动失败时，记录日志且主 API 仍可响应。
