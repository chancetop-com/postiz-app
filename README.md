# Postiz v2.26.0 upgrade facts

The schema delta adds five ordinary indexes across Post, Notifications, User and Errors. Index creation time and locking depend on the database and table sizes. The release also introduces optional encryption of stored channel credentials. Existing plaintext entries are readable with the default configuration. With encryption enabled, deployments must use matching keys on all processes that read those entries. [Official upgrade notes](https://github.com/gitroomhq/postiz-app/releases/tag/v2.26.0) · [Schema at release](https://github.com/gitroomhq/postiz-app/blob/132859f32d854830ce44b509da87409c3ec10a77/libraries/nestjs-libraries/src/database/prisma/schema.prisma) · [Encryption service](https://github.com/gitroomhq/postiz-app/blob/132859f32d854830ce44b509da87409c3ec10a77/libraries/nestjs-libraries/src/services/encryption.service.ts)

The tagged release adds a manual Temporal workflow to backfill old credential rows and changes activity-side credential handling. Existing workflow definitions compare equal across the two upstream tags. A downstream upgrade still needs to exercise outstanding jobs, refresh activities and compatible queues.
